# Templates

> Part of [knowledge-driven development](../README.md), which defines the marks.

A starting file per document kind in [04](../04-document-taxonomy.md), and the lines a repository's
agent instructions need. Copy, fill in, and delete what doesn't apply. An empty section is worse than
an absent one, because a reader can't tell whether it's empty because there's nothing, or because
nobody wrote it.

| File | Kind | Perspective |
| --- | --- | --- |
| [feature.md](feature.md) | Feature | Whoever uses the capability |
| [journey.md](journey.md) | User journey | One actor, start to finish |
| [subsystem.md](subsystem.md) | Subsystem or integration | The engineer on call, and the integrator |
| [agent-instructions.md](agent-instructions.md) | Lines for `AGENTS.md` or `CLAUDE.md` | Every agent working in the repository |

The marks in these files are placeholders, which makes them mentions, not claims. Once a copy is filled
in, every mark in it is a claim about the system.
